# Zarpa desktop distribution

Official distribution repository for Zarpa desktop installers, authenticated update manifests and checksums.

macOS Apple Silicon is the first target. A release is published only after signing, notarization and artifact qualification. Windows downloads follow independent validation.

The application source and development history are managed separately. This repository does not publish the private source repository. Each distributed package includes its applicable software license and third-party notices.

Product and release availability: [zarpa.dev](https://zarpa.dev/).

Support and security reports: [machester4@gmail.com](mailto:machester4@gmail.com). Do not include credentials or customer application data.
